# Skillup — Landing Page

A responsive landing page for a fictional online learning platform, built as a front-end practice project using pure HTML & CSS (no frameworks, no JavaScript).

## Built With
- HTML5
- CSS3 — Flexbox & Grid

## Features
- Fully responsive layout (desktop, tablet, and mobile)
- Navigation bar built with Flexbox
- Hero section with a pure CSS "code editor" illustration — no images used
- Features section laid out with CSS Grid
- Pricing section with a highlighted "featured" plan
- Custom color palette using CSS variables

## What I Practiced
- Structuring a full page with semantic HTML
- Building responsive layouts with Flexbox and CSS Grid
- Writing media queries for mobile responsiveness
- Using CSS custom properties (variables) for a consistent design system
- Creating visual elements (like the code mockup) with pure CSS instead of images
